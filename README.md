# 🛍️ Amazon Homepage Clone

A pixel-perfect, high-fidelity frontend cloning project replicating the dense, multi-layered layout structure of the Amazon India homepage. This project was built completely from scratch using pure **HTML5** and **CSS3** to demonstrate mastery over complex UI layouts, component alignment, and structural grid management.

### 🔗 Live Deployment & Preview
* **Live Demo:** [https://amazon-clone-delta-swart.vercel.app/](https://sameer-amazon-clone.vercel.app/)

---

## 🎨 Layout & Visual Component Highlights

### 1. Multi-Tiered Header Navigation
* **Top Navbar:** Accurately structures localized delivery targets (`Delivering to Kanpur`), a unified search system with variable-width bounds, multi-language/country toggles, and multi-state menu triggers (`Account & Lists`, `Returns & Orders`, `Cart`).
* **Sub-Navigation Strip:** Uses flexible inline containers to manage secondary shopping categories cleanly without wrapping overflows unnecessarily.

### 2. Multi-Dimensional Card Grids
* **Hero Section Carousel:** Integrates a wide-aspect hero banner displaying live promotional material (`Holi must-haves`).
* **Quad-Product Feature Boxes:** Replicates the complex 4-quadrant grid containers (`Revamp your home in style`, `Appliances for your home`) featuring independent sub-captions and uniform internal bounding boxes.
* **Horizontal Product Sliders:** Implements fluid, multi-item row carousels for horizontal scroll showcases (`Smart storage, clutter-free living`, `Cookware, kitchen tool & more`).

### 3. Comprehensive Multi-Column Footer
* Features a modular, multi-panel breakdown (`Get to Know Us`, `Connect with Us`, `Make Money with Us`, `Let Us Help You`) built to maintain consistent line-heights, perfect padding ratios, localized country indices, and custom signature branding.

---

## 🛠️ Technical Focus & CSS Methodologies

* **Semantic HTML5 Architecture:** Avoided generic nesting soup by utilizing semantic landmarks (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`) to optimize structural readability.
* **Advanced CSS Grid & Flexbox:** Recreated complex layout structures purely through modern layout engines—utilizing multi-column grids for content panels and flex containers for inline item alignments.
* **Asset Mapping:** Managed accurate scaling ratios for varied product aspect images across multi-grid displays without distorting native proportions.
